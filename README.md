# OSAT-SCANNER
Extensión móvil del sistema trazabilidad del control de ensamblado de semiconductores.


Comando para ejecutar app en dispositivo fisico (la ip esta configurada para un emulador, para la tablet, si se utilizara el teléfono para pruebas reales de scaneo, se ocupa el siguiente comando):
flutter run --dart-define=API_HOST=127.0.0.1
